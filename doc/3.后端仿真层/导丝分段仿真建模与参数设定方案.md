# 导丝分段连续体仿真建模技术方案完善版

## 一、方案定位

本方案用于完善介入手术术前—术中全流程仿真中的导丝物理建模部分。目标不是把导丝建成一根均匀软线，而是将导丝建成具有临床功能差异、材料差异、控制响应差异和支撑状态差异的分段连续体模型。

原方案已经指出，导丝可以抽象为一串 body / cable 节点，每节之间通过关节或约束连接；早期 MuJoCo 模型中导丝是 N 节 body 链，后续 Newton/VBD 可映射为粒子链、距离约束、弯曲约束与扭转约束。

完善后的核心设计原则为：

```text
导丝 = 几何分段 + 材料分段 + 控制分段 + 支撑分段 + 风险评估分段
```

其中：

| 分段维度 | 解决的问题                                   |
| ---- | --------------------------------------- |
| 几何分段 | 远端 tip 可塑形，支持 J-tip / C / Angled / Hook |
| 材料分段 | 软头、过渡段、主杆身刚度不同                          |
| 控制分段 | push、pull、rotate 不直接等效传到 tip，而是通过连续体传导  |
| 支撑分段 | 导引导管 / 中间导管 / 微导管改变导丝约束状态               |
| 风险分段 | 不同段的接触风险、顶壁风险、屈曲风险不同                    |

---

## 二、导丝分段模型

### 2.1 分段结构

导丝从远端 distal tip 到近端 proximal root 分为 6 个功能段：

```text
远端 tip                                                近端 root
│                                                       │
▼                                                       ▼
圆滑无创头 ─ 预塑形软头 ─ 柔顺过渡段 ─ 扭转响应段 ─ 主支撑杆身 ─ 近端操控段
```

对应英文命名：

```text
[0] Atraumatic Cap
[1] Pre-shaped Soft Tip
[2] Flexible Transition
[3] Torque Response Segment
[4] Main Support Shaft
[5] Proximal Controlled Segment
```

原方案中也建议将导丝分为无创圆头、预塑形软头、柔顺过渡段、扭转响应段、主支撑杆身和近端导管约束段。
这里建议将最后一段从固定的 `Sheath-Constrained Segment` 改名为 `Proximal Controlled Segment`，因为“导管约束”不是导丝自身固定分段，而是由外部同轴支撑系统动态决定。

### 2.2 每段功能

| 分段                          | 临床意义                      | 仿真作用                       |
| --------------------------- | ------------------------- | -------------------------- |
| Atraumatic Cap              | 圆滑无创头                     | 降低尖端顶壁和穿管风险                |
| Pre-shaped Soft Tip         | J-tip / C / Angled / Hook | 找入口、选择分支、贴壁滑入              |
| Flexible Transition         | 软头后方柔顺区                   | 防止刚度突变，避免力突然传到血管壁          |
| Torque Response Segment     | 扭矩传导段                     | 近端 rotate 后，远端 tip 逐步转向    |
| Main Support Shaft          | 导丝主体                      | 传递推送力，提供整体支撑               |
| Proximal Controlled Segment | 近端操控段                     | 接收 push / pull / rotate 输入 |

原方案中已定义各段临床对应和仿真作用，可作为本表基础。

## 三、分段长度设计

### 3.1 初始比例

以有效仿真导丝长度 `L_wire` 为基准：

| 分段                          | 推荐长度比例 |    200mm 示例 |
| --------------------------- | -----: | ----------: |
| Atraumatic Cap              |   1–2% |       2–4mm |
| Pre-shaped Soft Tip         |  5–10% |     10–20mm |
| Flexible Transition         | 10–15% |     20–30mm |
| Torque Response Segment     | 15–25% |     30–50mm |
| Main Support Shaft          | 40–60% |    80–120mm |
| Proximal Controlled Segment |  剩余近端段 | 由总长度和插入状态决定 |

原方案给出的长度比例可以保留，但需注意：所谓“导管/sheath 内动态变化”的部分不应写成导丝固定分段，而应作为外部支撑系统对导丝 body 的动态状态标记。

### 3.2 动态支撑与固定分段的区别

导丝自身固定分段：

```text
cap / soft_tip / transition / torque / shaft / proximal_control
```

外部支撑状态：

```text
free
inside_microcatheter
inside_intermediate_catheter
inside_guiding_catheter
inside_sheath
```

因此同一个导丝 body 同时具有两个标签：

```python
body.material_segment = "torque_response"
body.support_state = "inside_microcatheter"
```

## 四、参数模型

### 4.1 基础参数

每个导丝段至少包含以下参数：

```python
@dataclass
class GuidewireSegmentParam:
    name: str

    start_ratio: float
    end_ratio: float

    radius_mm: float
    mass_scale: float

    stretch_stiffness: float
    bend_stiffness: float
    torsion_stiffness: float

    stretch_damping: float
    bend_damping: float
    torsion_damping: float

    contact_radius_mm: float
    contact_ke: float
    friction_static: float
    friction_dynamic: float

    precurve_angle_deg: float = 0.0
    precurve_radius_mm: float | None = None
    precurve_plane_deg: float = 0.0

    max_contact_force: float | None = None
    max_breach_mm: float | None = None
```

原方案已经列出每个 body / cable segment 应包含半径、质量、拉伸刚度、弯曲刚度、扭转刚度、阻尼、接触和预弯参数。

### 4.2 Newton/VBD 注意事项

在 Newton/VBD 中，分段参数应主要映射为：

| 参数                  | Newton/VBD 作用   |
| ------------------- | --------------- |
| `bend_stiffness`    | 控制局部弯曲能力        |
| `torsion_stiffness` | 控制近端旋转传到远端的能力   |
| `stretch_stiffness` | 控制轴向伸缩          |
| `contact_ke`        | 接触刚度            |
| `friction_dynamic`  | 与血管壁 / 导管内壁滑动阻力 |
| `precurve_*`        | 初始化 tip 的预塑形几何  |

注意：细杆当前应以 `SolverVBD` 为主线，不应继续假设 SolverXPBD 是默认细杆求解器；`stretch_damping` 默认建议设为 0 或极低，避免杆被拉散。原方案也已记录这一点。

## 六、Tip 形状参数化

### 6.1 TipShapeProfile

不同 tip 不应只是前端贴图变化，而应改变远端几何初始构型和局部刚度。原方案已经列出 Straight、Angled、J-tip、C-shape、Hook 等 tip 类型。

建议统一为：

```python
@dataclass
class TipShapeProfile:
    shape_type: Literal["straight", "angled", "j_tip", "c_shape", "s_shape", "hook"]

    tip_length_mm: float
    precurve_angle_deg: float
    precurve_radius_mm: float | None
    precurve_plane_deg: float

    soft_tip_length_mm: float
    cap_length_mm: float

    bend_stiffness_scale: float
    torsion_stiffness_scale: float

    max_push_speed_scale: float
    wall_poking_risk_scale: float
```

### 6.2 默认 tip 预设

| Tip 类型   | 推荐场景     | 参数特点                         |
| -------- | -------- | ---------------------------- |
| Straight | 直管、低角度分支 | `precurve_angle=0`           |
| Angled   | 中等分叉角    | `precurve_angle≈30°`         |
| J-tip    | 大曲率、分叉入口 | `precurve_angle≈60°`         |
| C-shape  | 急弯、宽腔找入口 | `precurve_angle≈90–120°`     |
| Hook     | 明显侧向入口   | `precurve_angle≈90°`，但顶壁风险较高 |
| S-shape  | 复杂迂曲路径   | 双曲率，需更复杂初始化                  |

## 七、body 离散化策略

### 7.1 非均匀离散

导丝不建议全长使用相同 body 间距。原方案已经建议远端高分辨率、近端低分辨率，以兼顾软头表现和性能。

推荐策略：

| 区域                      |    body 间距 |
| ----------------------- | ---------: |
| Atraumatic Cap          |  0.8–1.2mm |
| Pre-shaped Soft Tip     |      1–2mm |
| Flexible Transition     |        2mm |
| Torque Response Segment |      2–3mm |
| Main Support Shaft      |      3–5mm |
| 支撑管内段                   | 4–6mm，可约束化 |

### 7.2 分段离散函数

```python
def discretize_guidewire(profile: GuidewireProfile) -> list[WireNode]:
    nodes = []

    for segment in profile.segments:
        ds = segment.preferred_spacing_mm
        n = max(1, int(segment.length_mm / ds))

        for k in range(n):
            ratio = compute_ratio(segment, k, n)
            nodes.append(WireNode(
                arclen_mm=ratio * profile.total_length_mm,
                material_segment=segment.name,
                radius_mm=segment.radius_mm,
                bend_stiffness=segment.bend_stiffness,
                torsion_stiffness=segment.torsion_stiffness,
            ))

    return nodes
```

## 八、同轴支撑系统修正

### 8.1 为什么要修正

原方案中使用 `Sheath-Constrained Segment` 和 `sheath / catheter` 表述，容易让人误解为鞘管一路支撑到远端。实际建模应改为：

```text
同轴支撑系统 Coaxial Support System
= introducer sheath
+ guiding catheter
+ intermediate catheter
+ microcatheter
```

其中：

| 器械                    | 仿真角色              |
| --------------------- | ----------------- |
| Introducer Sheath     | 入口近端稳定，不负责远端弯道支撑  |
| Guiding Catheter      | 近端工作通道，提供整体支撑     |
| Intermediate Catheter | 把支撑点进一步送向远端       |
| Microcatheter         | 最靠近远端弯道，直接缩短导丝自由段 |
| Guidewire             | 远端自由软头负责选路和过弯     |

### 8.2 支撑系统数据结构

```python
@dataclass
class SupportTube:
    name: str
    tube_type: Literal[
        "introducer_sheath",
        "guiding_catheter",
        "intermediate_catheter",
        "microcatheter",
    ]

    tip_arclen_mm: float
    inner_radius_mm: float
    outer_radius_mm: float

    bend_stiffness: float
    axial_friction: float
    lateral_constraint_ke: float

    can_follow_wire: bool
    can_deliver_device: bool
    is_active: bool = True
```

```python
@dataclass
class CoaxialSupportSystem:
    sheath: SupportTube | None
    guiding_catheter: SupportTube | None
    intermediate_catheter: SupportTube | None
    microcatheter: SupportTube | None

    def effective_support_tip(self) -> float:
        active_tubes = [
            t for t in [
                self.sheath,
                self.guiding_catheter,
                self.intermediate_catheter,
                self.microcatheter,
            ]
            if t is not None and t.is_active
        ]
        return max(t.tip_arclen_mm for t in active_tubes)
```

### 8.3 导丝自由段计算

```python
free_wire_length_mm = guidewire_tip_arclen_mm - effective_support_tip_mm
```

解释：

| 情况    | 风险                          |
| ----- | --------------------------- |
| 自由段过长 | root 动、tip 不动，slack 增大，导丝屈曲 |
| 自由段适中 | 推力和扭矩能传到远端，tip 仍能自由选路       |
| 自由段过短 | 软头活动不足，难以选分支，可能像导管头顶壁       |

### 8.4 支撑状态标记

```python
def update_support_state(nodes, support_system):
    support_tip = support_system.effective_support_tip()

    for node in nodes:
        if node.arclen_mm <= support_tip:
            node.support_state = "inside_support_tube"
        else:
            node.support_state = "distal_free_span"
```

注意：

```text
inside_support_tube:
    允许轴向滑动
    允许旋转传导
    限制侧向位移
    限制自由屈曲

distal_free_span:
    允许自由弯曲
    允许贴壁滑入
    允许进入分支
    承担主要选路功能
```

## 九、NewtonEngine 接入设计

### 9.1 构造接口

```python
class NewtonEngine(PhysicsEngine):
    def __init__(
        self,
        planned_path: PlannedPath,
        guidewire_profile: GuidewireProfile,
        support_system: CoaxialSupportSystem,
        engine_params: NewtonEngineParams,
    ):
        self.guidewire_profile = guidewire_profile
        self.support_system = support_system
        self.engine_params = engine_params

        self.nodes = discretize_guidewire(guidewire_profile)
        self._build_segmented_wire()
        self._build_support_constraints()
```

### 9.2 分段物理构建

```python
def _build_segmented_wire(self):
    for node in self.nodes:
        segment = self.guidewire_profile.segment_at(node.arclen_mm)

        node.radius = segment.radius_mm
        node.mass_scale = segment.mass_scale

        node.stretch_stiffness = segment.stretch_stiffness
        node.bend_stiffness = segment.bend_stiffness
        node.torsion_stiffness = segment.torsion_stiffness

        node.contact_ke = segment.contact_ke
        node.friction_dynamic = segment.friction_dynamic

        if segment.precurve_angle_deg:
            self._apply_precurve(node, segment)
```

### 9.3 支撑约束构建

```python
def _apply_support_constraints(self):
    support_tip = self.support_system.effective_support_tip()

    for node in self.nodes:
        if node.arclen_mm <= support_tip:
            self._apply_lateral_constraint(node)
            self._allow_axial_sliding(node)
            node.support_state = "inside_support_tube"
        else:
            self._release_lateral_constraint(node)
            node.support_state = "distal_free_span"
```

## 十二、风险评估增强

### 12.1 分段风险

不同导丝段的风险判断不同：

| 分段                          | 主要风险          |
| --------------------------- | ------------- |
| Atraumatic Cap              | 顶壁、穿管         |
| Pre-shaped Soft Tip         | 误入分支、顶壁、贴壁失败  |
| Flexible Transition         | 刚度突变、局部折角     |
| Torque Response Segment     | 扭转滞后、方向控制失败   |
| Main Support Shaft          | slack、屈曲、推力耗散 |
| Proximal Controlled Segment | 过度输入、持续硬推     |

### 12.2 支撑相关风险

| 指标                       | 含义              |
| ------------------------ | --------------- |
| `free_wire_length_mm`    | 支撑点前方自由导丝长度     |
| `slack_mm`               | 喂入长度与 tip 实际前进差 |
| `pile_ratio`             | 盘绕 / 屈曲程度       |
| `support_ratio`          | 被支撑管约束的导丝比例     |
| `torsion_lag_deg`        | 近端旋转与远端响应差      |
| `normal_poking_score`    | 尖端顶壁风险          |
| `tangential_slide_score` | 贴壁滑入质量          |

### 12.3 风险状态机

## 十三、参数标定流程

原方案已经提出 5 个实验：自由弯曲、旋转传导、直管推送、大曲率过弯、顶壁失败测试。
建议将其升级为固定回归测试矩阵。

### 13.1 实验 1：自由弯曲测试

目标：

```text
验证 cap / soft tip / transition / main shaft 的弯曲梯度是否合理。
```

指标：

```python
max_tip_deflection_mm
curvature_continuity
shaft_deflection_ratio
```

验收：

```text
soft tip 明显弯曲
main shaft 不应过软
transition 曲率连续，无突变折角
```

### 13.2 实验 2：旋转传导测试

目标：

```text
近端旋转 90°，验证远端 tip 是否逐步响应。
```

指标：

```python
proximal_rotation_deg
distal_tip_rotation_deg
torsion_lag_deg
tip_response_time_ms
```

验收：

```text
远端 tip 有滞后，但不能完全不动
支撑点前移后 torsion_lag 应降低
```

### 13.3 实验 3：直管推送测试

目标：

```text
验证主支撑杆身 push 传导和 friction 参数。
```

指标：

```python
root_displacement_mm
tip_displacement_mm
slack_mm
contact_force
```

验收：

```text
tip 能稳定跟随 root
slack 不应快速积累
```

### 13.4 实验 4：大曲率过弯测试

目标：

```text
验证预塑形软头、旋转定向、微导管支撑、贴壁滑入。
```

流程：

```text
J-tip 进入大弯
→ rotate 定向
→ micro push
→ microcatheter 跟进
→ 再 micro push
```

指标：

```python
tip_progress
contact_force
breach_mm
free_wire_length_mm
wall_slide_score
```

验收：

```text
tip 可沿壁滑入
无 breach
支撑点前移后 buckling risk 降低
```

### 13.5 实验 5：顶壁失败测试

目标：

```text
故意让 tip 朝向外壁，验证系统是否阻止硬推。
```

指标：

```python
normal_poking_score
contact_force
breach_mm
hard_push_duration
```

验收：

```text
tip progress 停滞时系统报警
禁止继续 hard push
提示回撤、旋转或换 tip
```

## 十六、最终完善结论

完善后的导丝分段建模方案应从“静态分段说明”升级为“可配置、可仿真、可观测、可评分”的工程系统：

```text
GuidewireProfile 定义导丝自身分段
TipShapeProfile 定义远端软头形状
CoaxialSupportSystem 定义外部导管支撑
NewtonEngine 根据分段参数构建物理体
RiskAssessor 根据分段和支撑状态判断风险
Godot HUD 显示分段、支撑和风险状态
```

最终导丝不再是均匀 body 链，而是：

```text
软头找路
过渡段顺弯
扭转段传方向
主杆身传推力
同轴支撑系统前移支撑点
远端自由段完成真正的转弯和分支选择
```

这样才能把临床中的“预弯软头、旋转定向、导管支撑、小步推拉、贴壁滑入、失败换策略”完整映射到术前—术中介入仿真系统中。
