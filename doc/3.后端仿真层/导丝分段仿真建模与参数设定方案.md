# 导丝分段仿真建模与参数设定方案

## 一、总体原则

现有方案中，导丝已经可以抽象为一串 body / cable 节点，每节之间通过关节或约束连接；早期 MuJoCo 模型中导丝是 N 节 body 链，每节有 2-DOF 万向关节和 stiffness 参数，后续迁移到 Newton/VBD 后可映射为粒子链、距离约束、弯曲约束与扭转约束。

但如果所有节段参数完全一致，就无法表现真实导丝的关键特性：

1. 远端 tip 很软，可塑形；
2. tip 后方有过渡段，负责把方向传出去；
3. 主体段更硬，负责推送和支撑；
4. 近端被导管/sheath 包裹时，侧向屈曲受到约束；
5. 旋转不是瞬时到达远端，而是有扭转传导和滞后；
6. 失败时可能出现 slack、屈曲、顶壁、回弹。

因此建议采用：

```text
导丝 = 几何分段 + 材料分段 + 控制分段 + 支撑分段
```

---

## 二、推荐分段结构

建议将导丝从远端到近端分为 6 段：

```text
[0] Atraumatic Cap  无创圆头
[1] Pre-shaped Soft Tip  预塑形软头
[2] Flexible Transition  柔顺过渡段
[3] Torque Response Segment  扭转响应段
[4] Main Support Shaft  主支撑杆身
[5] Proximal / Sheath-Constrained Segment  近端导管约束段
```

可以理解为：

```text
远端 tip                                                近端 root
│                                                       │
▼                                                       ▼
圆头 ─ 预弯软头 ─ 过渡段 ─ 扭转响应段 ─ 主支撑段 ─ sheath/导管约束段
```

---

## 三、每段功能定义

| 段                          | 临床对应                      | 仿真作用                     |
| -------------------------- | ------------------------- | ------------------------ |
| Atraumatic Cap             | 圆滑导丝头端                    | 防止“针刺式”顶壁，降低尖端穿管         |
| Pre-shaped Soft Tip        | J-tip / C / angled / hook | 找入口、勾住目标分支方向             |
| Flexible Transition        | 软头后方柔顺区                   | 让 tip 可以贴壁滑入，不立刻把力硬传到血管壁 |
| Torque Response Segment    | 扭矩传导段                     | 近端 rotate 后，远端 tip 能逐步转向 |
| Main Support Shaft         | 导丝主体                      | 提供推送力和整体支撑               |
| Sheath-Constrained Segment | 导管/鞘管内导丝                  | 限制侧向屈曲，提供近端支撑            |

---

## 四、推荐长度比例

如果当前仿真导丝有效长度按 `L_wire` 计算，建议初始比例为：

| 段                          |   长度比例 | 示例：200mm 导丝有效段 |
| -------------------------- | -----: | -------------: |
| Atraumatic Cap             |   1–2% |          2–4mm |
| Pre-shaped Soft Tip        |  5–10% |        10–20mm |
| Flexible Transition        | 10–15% |        20–30mm |
| Torque Response Segment    | 15–25% |        30–50mm |
| Main Support Shaft         | 40–60% |       80–120mm |
| Sheath-Constrained Segment |   动态变化 |        由导管位置决定 |

注意：`Sheath-Constrained Segment` 不是固定长度，而是随导管/sheath tip 位置动态变化。导管越往前，导丝自由段越短，越不容易屈曲。

---

## 五、物理参数设计

每个 body / cable segment 至少应有以下参数：

```python
GuidewireSegmentParam:
    segment_name: str
    start_index: int
    end_index: int

    radius_mm: float
    mass_scale: float

    stretch_stiffness: float
    bend_stiffness: float
    torsion_stiffness: float

    stretch_damping: float
    bend_damping: float
    torsion_damping: float

    contact_radius_mm: float
    contact_ke: float
    friction_static: float
    friction_dynamic: float

    precurve_angle_deg: float
    precurve_radius_mm: float
```

在 Newton/VBD 路线下，需要特别注意：现有实测已经修正了早期 XPBD 判断，细杆应走 `SolverVBD`，不是 `SolverXPBD`；并且 `stretch_damping` 大于 0 可能导致杆被拉散，因此应谨慎处理，默认可设为 0。

## 六、分段参数初始建议

下面给一套**归一化初始参数**。不要把它理解成真实器械绝对参数，而是用于仿真调参的起点。

设：

```text
主支撑段 bend_stiffness = 1.0
主支撑段 torsion_stiffness = 1.0
主支撑段 stretch_stiffness = 1.0
```

则各段建议：

| 段                   | stretch |          bend | torsion | contact | friction | 说明         |
| ------------------- | ------: | ------------: | ------: | ------: | -------: | ---------- |
| Atraumatic Cap      |     0.6 |      0.05–0.1 |    0.05 |       低 |        低 | 最软、最安全     |
| Pre-shaped Soft Tip |     0.7 |       0.1–0.2 | 0.1–0.2 |       低 |        中 | 能弯、能贴壁     |
| Flexible Transition |     0.8 |       0.2–0.4 | 0.3–0.5 |       中 |        中 | 连接软头和硬身    |
| Torque Segment      |     0.9 |       0.5–0.8 | 0.8–1.2 |       中 |        中 | 负责旋转响应     |
| Main Shaft          |     1.0 |           1.0 |     1.0 |       中 |        中 | 提供推送       |
| Sheath-Constrained  |     1.0 | 受 sheath 约束增强 | 1.0–1.5 |       中 |       可调 | 防屈曲，允许轴向滑动 |

## 七、tip 形状参数化

不同 tip 不应只换贴图，而要改变远端几何初始构型。

### 7.1 Straight Tip

```python
tip_shape = {
    "type": "straight",
    "precurve_angle_deg": 0,
    "precurve_radius_mm": None
}
```

适合直血管、低分叉角。

---

### 7.2 Angled Tip

```python
tip_shape = {
    "type": "angled",
    "precurve_angle_deg": 30,
    "tip_length_mm": 8,
    "precurve_radius_mm": 8
}
```

适合中等分叉角。

---

### 7.3 J-tip

```python
tip_shape = {
    "type": "J",
    "precurve_angle_deg": 60,
    "tip_length_mm": 12,
    "precurve_radius_mm": 5
}
```

适合大曲率转弯和分叉入口选择。

---

### 7.4 C-shape

```python
tip_shape = {
    "type": "C",
    "precurve_angle_deg": 120,
    "tip_length_mm": 15,
    "precurve_radius_mm": 4
}
```

适合急弯，但容易在宽腔中甩动，需要导管支撑。

---

### 7.5 Hook

```python
tip_shape = {
    "type": "hook",
    "precurve_angle_deg": 90,
    "tip_length_mm": 8,
    "precurve_radius_mm": 3
}
```

适合分叉入口选择，但顶壁风险较高，应限制推力。

## 八、body 离散化设计

### 8.1 不建议全长均匀高密度

如果所有段都用同样短的 body，会增加计算量；如果全部用低密度，又会让软头弯曲不真实。

建议采用**远端高分辨率、近端低分辨率**：

| 区域             |    body 间距 |
| -------------- | ---------: |
| Cap + Soft Tip |      1–2mm |
| Transition     |        2mm |
| Torque Segment |      2–3mm |
| Main Shaft     |      3–5mm |
| Sheath 内段      | 4–6mm，可约束化 |

### 8.2 示例

假设有效仿真长度 200mm：

```text
Cap: 3mm / 1mm ≈ 3 bodies
Soft Tip: 16mm / 1.5mm ≈ 11 bodies
Transition: 24mm / 2mm ≈ 12 bodies
Torque: 40mm / 2.5mm ≈ 16 bodies
Main Shaft: 117mm / 4mm ≈ 29 bodies

总计约 70 bodies
```

这样比全长 1–2mm 均匀离散更省，但远端仍有足够分辨率表现塑形、贴壁和旋转定向。

## 九、sheath / catheter 对分段的动态影响

导管/sheath 不应被建成“另一个不动的视觉管子”，而应改变导丝段的约束状态。

### 9.1 支撑规则

对于位于导管/sheath 内的导丝 body：

```text
允许：轴向滑动、旋转传导
限制：侧向位移、过度弯曲、自由屈曲
```

### 9.2 动态状态

```python
for body in guidewire.bodies:
    if body.arclen < catheter_tip_arclen:
        body.constraint_mode = "catheter_supported"
    elif body.arclen < sheath_tip_arclen:
        body.constraint_mode = "sheath_supported"
    else:
        body.constraint_mode = "free"
```

### 9.3 支撑后的参数变化

| 状态                 | bend 行为 | lateral motion | buckling |
| ------------------ | ------- | -------------- | -------- |
| free               | 完全自由    | 可侧向移动          | 可能发生     |
| catheter_supported | 弯曲受限    | 限制在导管半径内       | 明显降低     |
| sheath_supported   | 强约束     | 近似同轴           | 很低       |

当前方案中 anti-buckle 已经验证了 sheath 自动模式和 slack budget 对减少盘绕有效，说明“缩短无支撑自由段”是正确方向。

## 十、导丝分段与 6 步临床流程的对应

| 临床流程 | 需要的导丝分段                                 |
| ---- | --------------------------------------- |
| 头端塑形 | `Pre-shaped Soft Tip`                   |
| 旋转定向 | `Torque Response Segment` + tip 朝向      |
| 导管支撑 | `Sheath-Constrained Segment`            |
| 小步推拉 | `Main Shaft` 推送 + slack 监控              |
| 贴壁滑入 | `Atraumatic Cap` + `Soft Tip`           |
| 换策略  | 可替换 `TipShapeProfile` / `DeviceProfile` |

---

## 十一、推荐 `DeviceProfile` 结构

```python
@dataclass
class GuidewireProfile:
    name: str
    total_length_mm: float
    radius_mm: float

    tip_shape: str
    tip_curve_angle_deg: float
    tip_curve_radius_mm: float

    segments: list[GuidewireSegmentParam]

    max_push_speed_mm_s: float
    max_pull_speed_mm_s: float
    max_rotate_speed_deg_s: float

    max_contact_force: float
    max_slack_mm: float
    max_breach_mm: float
```

示例：

```python
J_TIP_SOFT_GUIDEWIRE = GuidewireProfile(
    name="soft_j_tip_training_wire",
    total_length_mm=200.0,
    radius_mm=0.18,

    tip_shape="J",
    tip_curve_angle_deg=60.0,
    tip_curve_radius_mm=5.0,

    segments=[
        Segment("cap", 0, 3, bend=0.08, torsion=0.05),
        Segment("pre_tip", 3, 14, bend=0.18, torsion=0.18),
        Segment("transition", 14, 26, bend=0.35, torsion=0.45),
        Segment("torque", 26, 42, bend=0.70, torsion=1.10),
        Segment("shaft", 42, 71, bend=1.00, torsion=1.00),
    ],

    max_push_speed_mm_s=3.0,
    max_pull_speed_mm_s=5.0,
    max_rotate_speed_deg_s=90.0,

    max_contact_force=1.0,
    max_slack_mm=12.0,
    max_breach_mm=0.3,
)
```

## 十二、参数标定流程

不要一次性手调所有参数，建议按 5 个实验逐级标定。

### 实验 1：自由弯曲测试

目的：验证软头、过渡段、主干段刚度差异。

操作：

```text
固定近端 → 给远端横向小力 → 观察弯曲曲线
```

验收：

* soft tip 明显弯曲；
* main shaft 不应像橡皮筋一样软；
* transition 曲率连续，无突变折角。

---

### 实验 2：旋转传导测试

目的：验证近端 rotate 能否传到远端 tip。

操作：

```text
近端旋转 90° → 观察 distal tip 旋转响应
```

指标：

```python
torsion_lag_deg = proximal_rotation_deg - distal_tip_rotation_deg
tip_response_time
```

验收：

* 远端 tip 有滞后，但不能完全不动；
* sheath 支撑越充分，旋转传导越稳定；
* 宽腔自由段过长时允许出现扭转损失。

---

### 实验 3：直管推送测试

目的：验证 stretch / push / friction 参数。

操作：

```text
直管内持续微推 → 观察 tip 与 root 前进差
```

验收：

* root 推进后 tip 应跟随；
* slack 不应快速积累；
* 接触力低且稳定。

---

### 实验 4：大曲率过弯测试

目的：验证软头贴壁滑入和导管支撑。

操作：

```text
J-tip 进入大曲率弯道
旋转定向 → 微推 → 导管跟进 → 再微推
```

验收：

* tip 能沿壁滑入；
* contact_force 可升高但 breach 不应出现；
* 若无 sheath 支撑，允许出现屈曲风险；
* 加支撑后屈曲明显降低。

---

### 实验 5：顶壁失败测试

目的：验证失败策略。

操作：

```text
故意让 tip 朝向外壁，然后持续 push
```

验收：

* tip progress 停滞；
* contact_force / normal_poking_score 上升；
* 系统禁止继续硬推；
* 提示回撤、旋转或换 tip。

---

## 十三、推荐参数调节顺序

调参不要乱调，建议固定顺序：

```text
1. 几何长度与 body 数
2. tip 形状
3. bend stiffness
4. torsion stiffness
5. contact / friction
6. sheath 支撑强度
7. push / rotate 速度限制
8. safety 阈值
```

不要先调 safety 阈值，否则会掩盖物理模型问题。

## 十四、不同训练难度的导丝配置

### 初学者模式

```text
soft tip 更长
bend 更软
推送速度更低
风险提示更早
允许轻度辅助定向
```

### 标准训练模式

```text
中等软头
真实扭转滞后
正常 sheath 约束
风险提示按物理状态触发
```

### 高级模式

```text
更短软头
更强主体刚度
宽腔中更容易甩动
提示减少
失败后需要自行换策略
```

## 十六、最终建议

导丝分段建模建议采用如下默认方案：

```text
远端 1–2%：圆滑无创头，极软，低接触风险
远端 5–10%：预塑形软头，决定 J/C/S/Hook 形状
远端 10–15%：柔顺过渡段，避免力突变
中段 15–25%：扭转响应段，负责 rotate 传导
近端 40–60%：主支撑杆身，负责 push 传导
导管/sheath 内：动态约束段，限制屈曲，允许轴向滑动
```

一句话总结：

> 仿真导丝不能只是一串均匀 body，而应是“软头找路、过渡段顺弯、扭转段传方向、主干段传推力、导管段给支撑”的分段连续体模型。

这样才能把临床中的“预弯软头 + 旋转定向 + 导管支撑 + 小步推拉 + 贴壁滑入 + 失败换策略”真正体现在物理仿真里。
