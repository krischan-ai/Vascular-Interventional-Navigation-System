## 一、实验目的

1. 理解强化学习中智能体、环境、观测、动作、奖励和回合之间的关系。
2. 掌握近端策略优化算法（Proximal Policy Optimization，PPO）的基本训练过程。
3. 验证 CathSim 导丝导航环境能否完成“采集经验—更新策略—评估模型”的完整实验过程。
4. 学会使用成功率、路线进度、回合长度、接触指标和结束原因分析训练结果。
5. 区分“训练程序正常完成”和“策略已经学会导航”两种不同结论。
6. 为后续算法、导丝参数和路线难度对照实验建立统一方法。

---

## 二、实验原理

### 2.1 导丝导航的强化学习过程

本实验将导丝控制策略作为智能体，将血管、规划路线和物理仿真组成的导航任务作为环境。

每个时间步执行以下过程：

```text
读取导丝状态
  → 策略输出动作
  → 物理环境执行动作
  → 计算新状态和奖励
  → 保存本次交互经验
```

策略的主要输入包括：

- 导丝尖端姿态；
- 当前路线方向；
- 已完成路线进度；
- 尖端与路线的偏差；
- 接触和风险信息。

策略输出形状意图动作，再由导航控制器转换为导丝推进和旋转操作。

### 2.2 奖励的作用

奖励用于评价每一步动作。沿目标路线前进会获得正向反馈；偏离路线、动作不平滑、接触血管壁、回退或失败会受到惩罚。

总奖励只是学习信号，不能单独代表实验成功。评价策略时还必须观察：

- 是否到达目标；
- 最终进度和最大进度；
- 是否发生回退；
- 回合如何结束；
- 是否存在较大接触或穿透。

### 2.3 PPO 的基本思想

PPO 先使用当前策略与环境交互，收集一批样本，再根据这些样本更新策略。

本实验每批采集 2048 个环境时间步，共训练 4096 步：

```text
第 1～2048 步：采集第一批样本并完成第一次更新
第 2049～4096 步：采集第二批样本并完成第二次更新
```

选择 4096 步是为了观察两个完整的 PPO 训练周期，不是为了证明策略已经收敛。

## 三、实验问题与假设

### 3.1 本次实验问题

> 在固定血管、固定路线和固定随机种子的条件下，PPO 是否能够完成 4096 个环境时间步的训练，并在训练过程中正常进行策略更新和评估？

### 3.2 实验假设

- 原假设 H0：训练不能完整进行，或训练后模型不能进行独立评估。
- 实验假设 H1：训练能够完成两个 PPO 采样周期，且训练后的模型能够执行独立评估。

### 3.3 结果解释范围

如果实验假设成立，只能说明本次训练方法和实验环境能够正常配合。

本实验不直接验证：

- 策略已经收敛；
- 策略具有较高成功率；
- 策略能够适应其他血管和路线；
- 策略已经满足介入手术安全要求。

## 五、实验变量

### 5.1 自变量

本次为单组验证性实验，不主动改变算法或环境条件。主要观察训练时间步从 0 增加到 4096 时，训练过程和评估结果的变化。

后续对照实验可分别改变：

- PPO 与 SAC；
- 默认导丝与缩短导丝；
- 形状意图动作与直接动作；
- 训练时间步；
- 训练随机种子；
- 路线难度。

每次对照只改变一个主要因素。

### 5.2 控制变量

本次固定：

- 血管模型和目标路线；
- 观测与动作方式；
- 奖励和终止规则；
- 物理引擎；
- 训练随机种子；
- 训练和评估频率。

### 5.3 因变量

需要记录：

- 实际训练时间步；
- 训练回合奖励；
- 训练回合长度；
- 训练期评估奖励；
- 独立评估成功率；
- 最终进度和最大进度；
- 回合步数；
- 结束原因；
- 接触积分、最大接触和最大穿透。

## 六、实验步骤

### 6.1 实验准备

1. 检查 `endpoint_0` 的路线长度和路径点数量。
2. 检查 Python、PyTorch、Gymnasium、Stable-Baselines3 和 CathSim 是否能正常加载。
3. 运行导航环境、训练程序和评估程序的单元测试。
4. 确认训练使用 PPO、Newton 物理引擎和 `shape_intent` 动作。

### 6.2 训练实验

1. 使用随机种子 0 初始化环境和 PPO 策略。
2. 让策略采集第一批 2048 步经验。
3. 根据第一批经验更新策略和价值网络。
4. 在第 2048 步附近进行 5 回合评估。
5. 继续采集第二批 2048 步经验并再次更新策略。
6. 在第 4096 步附近进行第二次 5 回合评估。
7. 结束训练并保留 2048 步、4096 步、训练期最佳和最终模型。

### 6.3 独立评估

1. 关闭模型参数更新。
2. 使用确定性动作分别评估训练期最佳模型和最终模型。
3. 记录每回合的成功情况、奖励、步数、进度、接触和结束原因。
4. 检查观测和奖励中是否出现 NaN 或 Inf。

## 八、实验判定标准

### 8.1 本次实验通过条件

以下条件全部满足时，判定 4096 步训练实验完成：

1. 实际训练达到 4096 步；
2. 完成两次 PPO 样本采集和更新；
3. 在 2048 和 4096 步各进行一次训练期评估；
4. 保留两个阶段的模型以及最终模型；
5. 训练和评估数值中没有 NaN 或 Inf；
6. 最终模型能够完成至少一个独立评估回合。

### 8.2 策略能力判定

训练过程通过不等于策略能力通过。策略能力还应满足：

- 回合达到 98% 成功进度；
- 成功率达到实验开始前规定的标准；
- 不是依靠碰撞、穿透或过度接触完成任务；
- 在多个实际不同的测试条件下仍能保持稳定表现。

本课程实验暂以 90% 冻结测试成功率作为后续研究性目标，该数值不是临床安全标准。

## 九、后续对照实验设计

| 实验 | 对照内容 | 研究目的 |
|---|---|---|
| 实验一 | 20k 与累计 100k SAC | 判断增加训练时间是否改善性能 |

| 实验五 | 训练种子 0～4 | 分析训练结果的稳定性 |
| 实验六 | 不同物理参数和初始姿态 | 分析策略的鲁棒性 |
| 实验七 | 短路线、长路线和多分支路线 | 分析策略的路线泛化能力 |

后续实验应同时报告成功和失败情况，不能只选择表现最好的模型。
