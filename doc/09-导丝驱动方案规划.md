# 导丝驱动方案规划：从最小演示到真物理（A/B/C 对比 + 路线图）

> 关联 [doc/08 Warp/Newton 迁移](08-导丝物理迁移技术方案-Warp-XPBD-Newton.md)（D2 真腔 / D3 接线）。
> 本文**只做规划，不写代码**。目的：在"驱动方式"这个分叉上选一条**既能今天跑通、又不与最终真物理目标冲突**的路。

## 〇、问题复述（为什么当前演示不稳）

最小演示当前驱动 = **只把导丝近端(root)沿中心线瞬移，其余杆体自由跟随**。实测（A6000，扫 bend 1→400）：

| bend | tip–root 弧长跨度 起→终 | 脱壁量 |
|---|---|---|
| 1（软） | 55mm → **−51mm**（盘绕） | 9.0mm |
| 100 | 55 → −59mm | 7.7mm |
| 400（硬） | 55 → −62mm（弯道卡死） | 6.5mm |

**结论：调参救不了。** 软杆被近端一推就屈曲盘绕，硬杆过不了弯，两头都脱出管壁。

**根因不是"Newton 穿不了线"，而是演示缺了"入口支撑"。** 真实导丝是穿在**导管/鞘(catheter/sheath)**里推进的：在鞘内的那段被约束住（不会屈曲），只有**伸出鞘的远端**是自由的、靠物理与血管壁互动导航。当前演示只钉了 1 个点、没有鞘，于是近端一推就屈曲——这是**建模缺失**，不是求解器极限。

→ 这条洞察把"A/B/C 三选一"变成了**同一架构上的一个连续参数：自由段长度**。下面先逐项对比，再给统一架构与分期。

## 一、三方案本质与差异

| | A. 协同穿线（运动学） | B. 软引导物理（弹簧拉向中心线） | C. 真物理 D2（自由杆+真腔SDF） |
|---|---|---|---|
| **本质** | 整根杆每步被设到中心线采样点，tip 先行 | 杆自由模拟，但每个 body 被弹簧拉向中心线目标 | 近端推力驱动，杆靠列强度+接触自行穿行 |
| **稳定性** | 最稳（位置直接给定） | 稳（弹簧兜底） | 难（屈曲/脱垂/接触发散，需精调） |
| **物理真实度** | 无（位置全靠脚本，Newton 只是渲染） | 中（接触/弯曲是真的，但被弹簧"作弊"拉住） | 高（近似真实力学） |
| **工作量** | 小（≈现有 KinematicEngine 换渲染） | 中（要给每 body 加目标力/弹簧） | 大（鞘模型+刚度锥度+摩擦+substep/CCD 调试） |
| **今天能否跑通** | 能 | 能 | 不保证 |
| **接触力/贴壁/脱垂可见** | ❌ | 部分（弹簧抑制） | ✅ |
| **能否喂 RL 训练** | ❌ 无动力学可学 | ⚠️ 弹簧是拐杖，策略学的不是真导航 | ✅ 策略推/转→物理决定结果 |
| **对路线图（doc/08 RTX/RL/ROS）** | **死路**：不练求解器，将来全弃 | **过渡**：可逐步松弛弹簧趋向 C | **终点**：RL/数字孪生要的就是它 |

**一句话差异**：A 是"会动的假人"，C 是"真导丝"，B 是"被牵着走的真导丝"。**A/C 是两个极端，B 是中间。**

## 二、关键重构：三者其实是一个架构的三个工作点

把"入口支撑"补进来后，统一架构是：

```
导丝 = [ 鞘内段(被约束跟随中心线) ] —— [ 自由远端 tip(真物理: 弯曲 + SDF 接触) ]
        ↑ 推进=鞘口沿中心线前移，带动整根                 ↑ 唯一自由、靠物理导航的部分
```

- **自由段长度 L_free** 是唯一关键旋钮：
  - `L_free = 0` → 退化成 **A**（全约束，纯运动学）。
  - `L_free = 短(1–2cm)` → 稳定 + 远端有真实弯曲/贴壁 = **"A 的稳定 + C 的物理尖端"**。
  - `L_free → 全长 + 入口仅鞘支撑` → **C**（真物理穿行）。
- **B（全局弹簧）** 是另一种软化方式，但不如"鞘约束"干净：鞘模型对应真实解剖（导管支撑），而全局弹簧是非物理的外力。**所以推荐用"鞘约束 + 自由远端"实现软化，而不是 B 的全局弹簧。**

> 价值：这样 A/B/C 不再是"三选一一次性赌注"，而是**同一引擎里 L_free 从 0 长到全长**的渐进过程。每一步都在练真正的 Newton 求解器，没有一步是沉没成本。

## 三、推荐路线（分期，判据驱动，可回退）

| 阶段 | L_free | 碰撞 | 入口支撑 | 产出/判据 | 对应 doc/08 |
|---|---|---|---|---|---|
| **P1 现在** | 短(~1.5cm) | 程序化管腔 SDF（现有） | 鞘内段沿中心线约束 | 演示稳定：tip 先行、不脱壁、远端有真实弯曲+接触 | 补强 D3 接线 |
| **P2** | 中(~3–5cm) | **真血管 glb/seg.nrrd SDF** | 同上 + 刚度**锥度**（硬体软尖） | 远端真实贴壁/绕弯；真腔不穿隧 | **D2 真腔** |
| **P3 终点** | 全长 | 真腔 SDF + 摩擦 | 仅鞘口支撑 | 60Hz 实时；push/rotate→真物理导航；暴露给 RL | **D3 / 终点** |

- **P1 是"不返工的最小演示"**：改动小（newton_engine 的驱动从"钉 1 点"改成"钉鞘内段 + 放开远端 L_free"），今天能跑通，且**直接是 P2/P3 的骨架**。
- **判据贯穿**：稳定（不脱壁/不盘绕）+ tip 先行 + 远端可见真实物理；不是画面。
- **回退**：任何阶段受阻，把 L_free 调短即退回更稳的工作点，不推倒重来。

## 四、为什么不直接选 A 或 C

- **不选纯 A**：cathsim 已有 KinematicEngine（guided 模式）就是 A 的等价物。再做一个"Newton 版 A"是**重复劳动 + 物理死路**，对 RL/真手感零贡献。要做就让 Newton 至少跑**真实远端物理**。
- **不直接上纯 C**：稳定的"全自由杆物理穿行"是 cathsim 的**核心研究难题**（屈曲/脱垂/接触发散）。一上来全长自由 = 高概率今天跑不通、且难定位。**先短自由段把链路和远端物理跑顺，再逐步加长**，风险可控。
- **选"鞘约束 + 可调自由段"**：它**同时是** A 的稳定性、C 的演进终点、B 的可调性，且每个中间态都在练真求解器。**这是唯一"今天能跑 + 未来不弃"的选择。**

## 五、与现状的差距（P1 要动什么，仅规划）

1. **驱动**：`newton_engine.step` 当前只设 root 一个 body。改为：鞘内段（前 N 个 body，N 随 insert_s 增长）每步设到中心线目标；远端 L_free 段放开自由。
2. **入口几何**：把"沿中心线推进"= 鞘内段整体沿中心线前移（已有 `_point_at_s`，复用）。
3. **碰撞**：P1 仍用程序化管腔（够稳）；P2 换真腔 SDF（doc/08 §1.4 的 `visual/glb` 体素化或 `seg.nrrd` 距离变换）。
4. **中心线**：已重新居中（offset 0.43→0.17）；入口前 ~6 点贴壁是"开口端射线无法居中"的残留，P1 用"从首个居中点沿切线外推"补齐（规划项，未做）。
5. **参数**：刚度锥度（P2）、摩擦、substep/限速（D1 已给安全包络：SDF + ss≥40 + 限速）。
