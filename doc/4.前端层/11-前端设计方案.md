# Godot 医疗导航前端设计方案

本文档以最新参考图 `ChatGPT Image 2026年7月20日 11_59_08.png` 为准，用于指导 Godot 4 医疗导管/导丝机器人导航工作站前端开发。

核心目标：**复刻参考图的信息结构、窗口比例、深色医疗工业风、图标工具栏、数据密度、控制面板和训练/回放工作站质感**。不要重新设计成游戏 HUD，也不要做成普通后台 dashboard。

---

# 3. 顶部状态栏设计

顶部必须做成参考图那种**横向状态仪表条**，不是调试文字栏。

```text
背景：#101A26，透明度 90%-95%
边框：#25384A
圆角：8px - 10px
高度：约 80px - 96px
内部：横向排列，卡片之间有细分隔线
图标：线性医疗/设备图标，2px 描边
数值：大号数字，单位小号贴右侧
```

顶部模块从左到右：

```text
1. 机器人状态：已连接，绿色，机器人图标
2. 导航模式：手动，蓝色，罗盘图标
3. 路径进度：78 / 234 mm，蓝色进度条或圆环
4. 剩余距离：156 mm，蓝色
5. 模式分段控：HCI模式 / RL训练 / 策略推理
6. 血管半径：2.3 mm，蓝色
7. 曲率：0.015 1/mm，蓝色
8. 距血管壁距离：0.23 mm，红色
9. 风险等级：中风险或高风险，黄色/红色警告图标
10. 紧急停止：红色大按钮，右侧固定
```

模式分段控：

```text
位置：顶部中间
选中态：蓝色背景 #123A70，边框 #2F8CFF

必须看起来像医疗工作站模式切换，不是普通 Tab 页。
```

# 5. 腔镜实时视图窗口

```text
编号标题：2 腔镜实时视图
位置：中间上方
背景：红橙色内腔镜画面
边框：#25384A
圆角：8px
右上角：绿色 LIVE 状态点
```

画面要求：

```text
1. 必须有红橙色腔道组织质感。
2. 中央显示导丝/器械尖端。
3. 参考图为双腔/分叉结构，应优先表现两个前方通道。
4. 画面带轻微暗角、噪声、径向深度感。
5. 不能只是纯色矩形或普通噪声图。
```

底部控制条：

```text
位置：窗口底部
内容：相机按钮、录制红点、时间 00:12:36、亮度/曝光滑条、截图按钮、全屏按钮
风格：深色半透明条，细边框，小图标按钮
```

实现建议：

```text
阶段 1：使用程序纹理 + shader/绘制生成腔镜占位画面。
阶段 2：接入独立 SubViewport + EndoscopeCamera，绑定导丝 tip 第一人称视角。
阶段 3：用血管内壁材质、暗角、深度雾、导丝尖端模型替换占位图。
```

# 6. 3D 解剖导航窗口

```text
编号标题：3 3D解剖导航
位置：中间下方
背景：#050B12 或纯黑
边框：#25384A
圆角：8px
```

内容要求：

```text
1. 显示血管树模型，颜色为橙红/棕红，带医学 3D 质感。
2. 显示蓝色/青色导管或导丝路径。
3. 显示目标点和当前 tip 位置。
4. 模型居中，占窗口 70%-85%，不要撑满或被裁切。
5. 左下角显示方向罗盘：S/P/R/L 等方位标记。
6. 右侧竖向工具栏：旋转、层级、显示、定位、全屏。
7. 默认使用外部导航视角，不要自动切到内窥镜视角。
```

交互：

```text
鼠标左键拖拽：旋转观察
滚轮：缩放
单击路径点：可进入点击导航
复位：恢复临床视角
跟随：可手动切换导丝跟随视角，但不作为默认启动视角
```

参考图右上大面板不是普通 2x4 卡片，而是**导航数据 + 半圆仪表 + 接触力趋势图 + 小指标组合**。

```text

位置：右侧上方
面板背景：#101A26
边框：#25384A
圆角：8px
```

上部布局：

```text

- 标题：导航进度
- 主数值：78 / 234 mm
- 横向进度条：蓝色
- 百分比：33%

中间：距离终点半圆仪表
- 标题：距离终点
- 半圆进度弧：绿色到黄色渐变
- 主数值：156 mm
- 小字：剩余距离

右侧：接触力趋势图（N）
- 折线：绿色
- 风险阈值线：黄色/橙色虚线
- 告警阈值线：红色虚线
- 背景网格：#26394D 低透明度
```

下部小指标：

```text
1. 偏离中心线：2.3 mm，蓝色
2. 局部曲率：0.015 1/mm，蓝色
3. 推进速度：0.8 mm/s，蓝色

6. 风险等级：中风险，黄色警告图标
```

状态映射：

```text
壁距 > 1.5 mm：安全，绿色
```
