# 三维血管导航渲染开发计划

基于 `doc/12-三维血管导航渲染改造方案.md` 和当前代码状态制定。目标是把 Godot 3D 血管视图从工程调试感推进到医学影像式玻璃血管导航视图，同时保持真实风险数据优先、渲染资产与物理资产分离。

## 当前状态

- `godot_client/scripts/main_controller.gd` 已有 Fresnel 玻璃血管材质、近相机淡出、tip-centered orbit、导丝前端姿态提取。
- `godot_client/scripts/main_controller.gd` 已固定 `_path.set_risk_ranges([])`，不再使用 60% 路径段 mock 禁入区。
- `godot_client/scripts/path_renderer.gd` 已有路径曲率渐变、进度暗化和发光线，但注释与命名仍残留 risk/no-go 语义。
- `godot_client/scripts/guidewire_renderer.gd` 已按视角区分导丝与 tip 半径，但 overview tip 仍偏标记球。
- `tools/export_godot_assets.py` 目前 VPP 默认 `--max-faces 120000`，缺少 `visual_high`、`no-decimate`、smooth normals、Taubin smoothing 等高质量视觉导出管线。
- `services/navigation_engine.py` 已有 `risk_regions` 字段，但 `_risk_regions()` 仍会生成无 `source` 的 path deviation warning placeholder；未来前端空间风险渲染必须拒绝这类 placeholder。

## 开发顺序

1. P0：风险语义收口和测试保护。
2. P0：高质量视觉 GLB 导出管线。
3. P1：血管玻璃材质参数化与调参。
4. P1：Clinical Orbit 相机预设。
5. P2：路径与导丝 overlay 细化。
6. P2：景深/远端层次。
7. P3：真实 `risk_regions` 渲染器。

## V0：风险语义收口

目标：彻底区分“路径曲率提示”和“真实空间风险区”，避免视觉误导。

开发项：

- `path_renderer.gd`
  - 将 `_risk_ranges` / `set_risk_ranges()` 视为兼容旧入口，内部只允许空数组或改名为更中性的 forced ranges。
  - 清理注释中的 mock 禁入区、red override、danger 语义，改为 curvature heat hint。
  - 降低路径最高曲率颜色的红色饱和度，避免被误解为禁入体积。
- `main_controller.gd`
  - 保留 `_path.set_risk_ranges([])`，或改为更明确的 `_path.clear_forced_ranges()`。
  - 暂不消费 `safety.risk_regions` 渲染空间体，直到 V6。
- 测试
  - 继续保持 `tests/test_frontend_contract.py` 对 `_risk_volume`、`nogo_lo` 的禁止。
  - 增加测试：缺少 `source` 的 `risk_regions` 不会被前端空间渲染器消费。

验收：

- 搜索不到 `_risk_volume`、`nogo_lo`、mock no-go 相关入口。
- 默认画面无红色禁入体积。
- 曲率提示不会被命名为真实 risk/no-go。

## V1：高质量视觉资产导出

目标：解决低模折面感，这是参考图观感差距最大的来源。

开发项：

- `tools/export_godot_assets.py`
  - 新增 `--quality visual_high|preview`。
  - 新增 `--no-decimate`。
  - 新增 `--smooth-normals`。
  - 新增 `--taubin-smooth-iter N`，可用时调用 `trimesh.smoothing.filter_taubin`。
  - `visual_high` 默认 `--max-faces 300000`，`preview` 沿用 120000 或更低。
  - 输出文件区分 `blood_vessels_visual_high.glb`、`blood_vessels_preview.glb`、`segment_part_visual_high.glb`。
- `main_controller.gd`
  - `_resolve_vessel_glb()` 优先查找 `*_visual_high.glb`，缺失时回退现有 `*.glb` 并打印 warning。
- 测试
  - 测 CLI 参数解析。
  - 测 `--no-decimate` 不调用 decimation。
  - 测输出路径命名。

验收：

- `segment_part` 或 VPP 血管近景没有明显三角折面。
- 视觉 GLB 与 collision/SDF 资产路径分离。
- 导出脚本在缺少 optional backend 时能清晰降级。

## V2：医学玻璃血管材质

目标：从“整体发光实心管”变成“透明核心、边缘 Fresnel 高光、远端暗化”的玻璃血管。

开发项：

- `main_controller.gd::_make_fresnel_material()`
  - 参数起点：`rim_color = (0.20, 0.68, 1.00)`、`core_color = (0.02, 0.08, 0.18)`、`core_alpha = 0.02-0.05`、`rim_power = 2.0-2.6`、`glow = 2.2-3.0`。
  - 增加基于导丝 tip 距离的远端 alpha/emission 衰减。
  - 保留近相机 fade，避免血管贴镜头时糊成一团。
- `_setup_environment()`
  - 微调 glow，避免主体整片 cyan 过曝。
  - 保持 ACES tonemap。

验收：

- 主血管边缘有可见 bloom，中心透明。
- 远端分支暗一些，不与主血管抢焦点。
- 导丝 tip 不被 bloom 淹没。

## V3：Clinical Orbit 相机预设

目标：默认首屏更接近参考图的近景斜俯视，而不是全树工程视角。

开发项：

- `main_controller.gd`
  - 新增 `Clinical Orbit` 默认预设：围绕导丝 tip，近景斜俯视。
  - 保留 `Tree Overview` 作为复位/调试视图。
  - 保留现有 `Follow` 和 `Endoscope`。
- `_frame_camera()`
  - 若 `_tip_world_known`，以 tip 为 pivot，距离按局部血管尺度或 AABB 半径下限自适应。
  - FOV 维持 38-45，pitch 约 25-45 度。
- `_reset_view()`
  - 回到 `Clinical Orbit`，不要跳回目标点、入口点或全树中心。

验收：

- 首屏主血管占据画面主体。
- 左键拖拽始终围绕导丝 tip。
- 复位不回到全树工程视角，除非用户明确选择 Tree Overview。

## V4：路径与导丝 overlay 细化

目标：路径/导丝像导航叠加层，不像实体白管。

开发项：

- `path_renderer.gd`
  - `path_radius_main` 下调 20%-40%。
  - `emission_energy` 略升，`ALPHA` 降低。
  - 降低最高曲率颜色的红色饱和度。
- `guidewire_renderer.gd`
  - `tip_radius_overview` 适当缩小。
  - tip 材质提高对比但降低遮挡体积。
  - root/target/entry marker 只在必要模式或交互时显示。

验收：

- 导丝位置清楚。
- 路径线细亮，不压过血管边缘。
- 标记点不被误认为风险区。

## V5：景深与远端层次

目标：形成“tip 附近清晰，背景分支可辨但退后”的层次。

开发项：

- 先试 Godot Camera3D DOF。
  - focus distance = camera 到 `_tip_world_last` 的距离。
  - far blur 轻度开启。
- 若 DOF 效果不稳定，改用 shader 距离衰减。
  - 离 tip 越远，alpha/emission 越低。
  - 远端分支偏暗蓝。
- 每帧在 `_feed_rig()` 或相机更新处刷新 tip focus 参数。

验收：

- tip 附近血管最清楚。
- 背景分支不消失，但明显退到背景层。
- 拖拽/缩放后焦点仍跟随 tip。

## V6：真实风险区渲染

目标：只有后端真实空间风险数据到位时才显示红/橙体积。

前置契约：

```json
{
  "id": "stenosis_001",
  "level": "warning|danger",
  "kind": "stenosis|collision|no_go|high_curvature",
  "center": [0.0, 0.0, 0.0],
  "radius": 0.008,
  "orientation": [0.0, 0.0, 0.0, 1.0],
  "extent": [0.008, 0.008, 0.008],
  "source": "sdf|annotation|planner"
}
```

开发项：

- 新增 `godot_client/scripts/risk_region_renderer.gd`。
- `main_controller.gd` 只将有 `source` 的 regions 交给 renderer。
- `warning` 显示薄橙 halo，`danger` 显示低 alpha 红色体积。
- 没有 `source`、没有 `center`、没有 `radius/extent` 的 region 一律跳过。

验收：

- `risk_regions=[]` 时画面无空间风险体。
- 缺 `source` 的 placeholder 不显示。
- 真实 region 显示位置与血管坐标一致。

## 近期建议迭代

第一轮只做 P0 + V1 + 少量 V2，避免同时调资产、材质、相机导致问题来源混在一起。

具体任务：

1. 清理 `path_renderer.gd` 的 mock risk 语义和饱和红路径提示。
2. 给 `tools/export_godot_assets.py` 增加 `visual_high` / `preview` 质量参数和导出命名。
3. 让 Godot 优先加载 `*_visual_high.glb`，缺失时回退。
4. 小幅微调 Fresnel 参数，减少实心 cyan 感。
5. 跑 `pytest tests/test_frontend_contract.py tests/test_navigation_engine.py tests/test_websocket.py`。

## 验收清单

视觉验收：

- 近景无明显低模折面。
- 主血管边缘蓝色 bloom，中心不过曝。
- 远端分支较暗，不抢焦点。
- 默认视角围绕导丝前端，而不是目标点/入口点/全树中心。
- 路径细亮，导丝清楚，目标/入口标记不过度遮挡。
- 无真实风险数据时，不出现红色禁入体积。

工程验收：

- Godot headless 加载无脚本错误。
- 前端契约测试禁止 mock 风险区回归。
- 高质量视觉 GLB 与物理/SDF 资产分离。
- 切换模型后血管、路径、导丝仍处于同一坐标系。
