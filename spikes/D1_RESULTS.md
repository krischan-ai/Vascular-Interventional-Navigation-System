# D1 gate 结果记录（Newton 碰撞：杆 vs 血管管腔）

> 对应 [doc/08 §五 D1](../doc/08-导丝物理迁移技术方案-Warp-XPBD-Newton.md)。
> 脚本：[`d1_tube_collision.py`](d1_tube_collision.py)、[`d1_sweep.py`](d1_sweep.py)。日期：2026-06-29。

## 结论：**D1 可行性通过**（杆能被管腔约束、过弯、施 push 推进）

亚毫米导丝杆在血管尺度管腔（lumen r=2.5mm）中：直管推进**完全居中**、90° 弯管
**被接住并绕过**（tip 推进 60–80mm），稳态不穿墙。**前提是用对配方**（见下）。
残留问题（瞬态尖端甩动、GPU 非确定性、快推穿隧）都有明确缓解手段，且本就是
doc §七 计划内 / 应在 D2 用真实几何+分段刚度标定时收敛。

## 验证过的配方（直接给 D2/`newton_engine.py` 用）

| 项 | 取值 | 理由 |
|---|---|---|
| 碰撞 | **SDF**（`mesh.build_sdf()` 挂到 mesh 上） | 连续距离+梯度，比离散 mesh 碰撞稳健得多 |
| 管腔建模 | **实心块里挖隧道**（厚壁，非薄壳） | 薄壳 SDF 两侧都是正区，杆一旦穿过会被**往外推**；厚壁则始终把杆推回腔内 |
| 接触刚度 | `ke ≈ 1e6` | 1e5 太软，硬尖端顶弯道会蠕变穿墙；1e6 顶住 |
| substeps | **40 /控制帧** | 快推/瞬态需要；少了会穿隧 |
| 尖端弯曲刚度 | **软尖** `bend≈2–5`（本杆 0.10m 尺度） | 真实导丝就是软尖；硬尖端顶死弯道外壁会蠕变穿墙 → 对应 cathsim 分段 `stiffness_scale` 锥度 |
| 推进速率 | 真实插入速 **≤0.1–0.2 m/s** | ≥0.5 m/s 远端会甩/穿隧（无 CCD 的 XPBD/VBD 限制） |

最终 headline（SDF，上述配方）：

```
D1a straight      v=0.05  -> tip_adv=150mm  steady=-2.10mm  breach=0%   PASS  (完全居中)
D1b curved 90deg  v=0.05  -> tip_adv= 80mm  steady=+0.00mm  breach=0%   PASS  (过弯不穿)
D1c curved        v=0.10  -> tip_adv= ~60mm steady~+0.1..0.5mm breach 0-15% PASS* (见非确定性)
```

## 关键发现 / 踩坑（对 D2/D3 有用）

1. **薄壁 SDF 是错的**：厚壁/实心挖隧道才对（= doc §1.4 的二值分割→SDF：腔内一号、腔外一号，单调）。
   薄壳 SDF 会把穿过的杆**往外排**，越穿越远（实测 SDF 比 mesh 还差，直到改厚壁）。
2. **接触刚度是主杠杆**：弯道蠕变随 `ke` 升而降（1e5→3.9mm，1e7→0.5mm）。但单靠 ke 不够，要配软尖。
3. **硬尖端会顶穿弯道**：bend=50 顶死外壁蠕变 2–10mm；bend=2–5 软尖顺弯道走，0% 穿墙。
   → 真实导丝软尖设计 / cathsim 分段刚度锥度是物理正解，不是 trick。
4. **快推穿隧确实存在**（doc §七 预言）：v≥0.5m/s 或 substeps 少 → 远端甩穿。缓解=SDF+多 substep+限速。
   注意：多 substep 不总线性改善（瞬态甩动复杂），主因是无连续碰撞（CCD）。
5. **GPU 非确定性**：同配置重复跑，稳态穿墙 0.14/0.29/0.49mm、breach_frac 0–15% 抖动
   （并行接触/atomic 顺序）。→ 测试**不能断言精确数值**，要用容差；必要时查 warp 确定性模式。
6. 驱动方式要**每 substep 平滑推进** root（不是每帧跳一下），否则注入速度冲击让远端甩动（伪故障）。

## 测量口径

杆各体到中心线折线的**垂直距离**（点到线段），穿墙量 = 该距离 + 杆半径 − 腔内半径。
`steady` = 末 25% 帧均值（稳态约束），`worst` = 全程峰值，`breach_frac` = 穿墙>0.5mm 的帧占比。
